# Hyperparameter Selection Summary (for PPT)

## Three Key Points:

• **K-fold CV**: Evaluated α across log range (10⁻⁵ to 10¹) using K-fold cross-validation

• **Dual Metrics**: Optimized α separately using **RMSE** (minimize) and **R²** (maximize)

• **Averaged Selection**: Final α = **mean of optimal α** from RMSE and R²
